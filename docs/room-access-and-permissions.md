# Доступ к комнатам и ограничения

## 1. Текущая модель доступа

Redaction выполняется только от имени самого отправителя события и только если:

- пользователь локальный;
- пользователь активен;
- у него есть валидный access token в `Synapse DB`;
- пользователь всё ещё состоит в комнате.

## 2. Почему membership обязателен

Matrix Client API проверяет актуальное право пользователя выпустить redaction в комнате.

Если пользователь уже вышел из комнаты, был исключён или забанен, redaction от его имени вернёт отказ. Поэтому приложение обязано делать preflight-проверку текущего membership до HTTP-запроса.

## 3. Что считается поддерживаемым

Поддерживаемый кандидат:

- локальный отправитель;
- current membership `join`;
- есть читаемый и валидный token;
- событие прошло базовый фильтр по TTL и `redactions`.

## 4. Что считается unsupported

- remote/federated отправитель;
- деактивированный локальный пользователь;
- локальный пользователь без валидного token;
- локальный пользователь, который уже не состоит в комнате.

Во всех этих случаях событие должно быть помечено как skipped, а не отправлено в Matrix API “на удачу”.

## 5. Как проверяется membership

Для текущего состояния комнаты используются read-only таблицы `Synapse`:

- `current_state_events`
- `room_memberships`

Логика проверки:

- найти актуальное `m.room.member` state event для пары `user_id + room_id`;
- убедиться, что соответствующий membership равен `join`.

## 6. Как это влияет на отчётность

Если событие пропущено из-за доступа, причина должна быть явной в run journal.

Минимальные причины, которые стоит различать:

- `remote_user_unsupported`
- `local_user_deactivated`
- `no_valid_access_token`
- `sender_not_in_room`

## 7. Практический вывод

Текущая архитектура intentionally ограничена.

Она хорошо работает там, где:

- сообщения принадлежат локальным пользователям;
- у этих пользователей есть рабочие токены;
- они всё ещё состоят в соответствующих комнатах.

Она не предназначена для гарантированного удаления событий “всех пользователей во всех комнатах”.
