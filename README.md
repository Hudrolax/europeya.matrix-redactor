# europeya.matrix-redactor

Python-приложение для планового удаления Matrix-сообщений через `m.room.redaction` на основе read-only данных из `Synapse DB`.

Текущая архитектура проекта:

- читает кандидатов из `Synapse DB` без записи в неё;
- поддерживает только локальных пользователей;
- берёт существующие user access token из таблиц `Synapse`;
- распределяет redaction'ы между пользователями в sender-aware round-robin режиме;
- пропускает события, если пользователь деактивирован, не имеет валидного токена или уже не состоит в комнате;
- отправляет redaction только через Matrix Client API;
- хранит журнал запусков во внутренней локальной БД приложения.

## Compose и окружения

`docker-compose.yml` внутри этого репозитория не является production-обвязкой конкретного сервера.

Его назначение:

- локальные и тестовые запуски;
- базовая reference-конфигурация runtime;
- заготовка, которую можно скопировать и адаптировать под конкретный production-сервер.

Production `docker-compose.yml` должен жить вне репозитория, рядом с конкретным deployment, потому что:

- он зависит от путей, сетевой схемы, volume mount'ов и других особенностей конкретного сервера;
- production-настройки запуска не должны случайно менять содержимое общего репозитория;
- обновление кода приложения и настройка конкретного production-runtime должны быть разведены.

Иными словами: репозиторий хранит шаблон compose, а реальный prod compose сопровождается отдельно.
